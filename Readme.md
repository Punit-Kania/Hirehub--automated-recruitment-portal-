# HireHub – Automated Recruitment Portal

HireHub is an automated recruitment portal designed to connect candidates and employers through a smart recruitment process.

## Modules

1. User & Authentication
2. Candidate & Resume Management
3. Job Management
4. Job Application Management
5. AI / Smart Candidate Matching
6. Interview Management
7. Admin & Analytics

## Technology Stack

- Frontend: React.js
- Backend: PHP
- Database: MongoDB
- API Communication: REST API / JSON
- Version Control: Git
